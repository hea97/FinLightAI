# FinLightAI UI 수정 요청 정리

## 1. 메인 화면 네비게이션 정리
- 문제: 왼쪽 네비게이션과 메인 화면 정보가 동일한 깊이로 보여 화면이 복잡해 보임
- 수정 방향:
  - 왼쪽 사이드바 제거
  - 상단 제품 네비게이션으로 핵심 화면 이동 제공
  - 앱 IA와 메인 화면 프레임 순서를 반드시 동일하게 맞추지 않음
- 우선순위: 높음
- 반영 여부: 완료

## 2. 버튼 상호작용 구현
- 문제: EN, 시장 선택, 뉴스 필터가 버튼처럼 보이지만 실제 상태 변화가 약함
- 수정 방향:
  - `button` 요소로 변경
  - 활성 상태 클래스 토글
  - EN/KO 토글과 시장별 핵심 문구 변경 연결
- 우선순위: 높음
- 반영 여부: 완료

## 3. 자산 포트폴리오 CTA 강조
- 문제: 사용자가 직접 자산을 추가해야 하는 기능인데 CTA 기준이 분리되어 있지 않음
- 수정 방향:
  - 빈 상태와 주요 CTA 컴포넌트 기준 마련
  - “자산 추가하기” 버튼을 주요 CTA로 사용
- 우선순위: 높음
- 반영 여부: 기준 파일 추가

## 4. 카카오 알림 설명 강화
- 문제: 사용자가 어떤 알림을 받는지 한 번에 이해하기 어려움
- 수정 방향:
  - 알림 유형 안내 섹션 기준 마련
  - 시장 급변, 관심 산업, 포트폴리오 위험, AI 브리핑 요약을 명시
- 우선순위: 중간
- 반영 여부: 기준 파일 추가

## 5. AI 브리핑 날짜 표시
- 문제: 브리핑 정보가 현재 기준인지 판단하기 어려움
- 수정 방향:
  - 기준일과 마지막 업데이트 시각 표시
  - 브리핑 헤더 컴포넌트 기준 마련
- 우선순위: 중간
- 반영 여부: 기준 파일 추가

## 6. 로그인 / 회원가입 플로우 개선
- 문제: 실제 가입 이후 흐름이 화면 구조에 명확히 드러나지 않음
- 수정 방향:
  - 로그인 -> 약관 동의 -> 정보 입력 -> 가입 완료 -> 마이페이지 또는 자산 등록 유도
  - 카카오 로그인과 이메일 로그인 모두 지원
- 우선순위: 높음
- 반영 여부: 문서화 완료
