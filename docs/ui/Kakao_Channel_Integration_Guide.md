# 카카오 알림 채널 방식 정리

## 핵심 원칙

FinLightAI의 카카오 알림은 개인 카카오톡 계정을 직접 연결하는 방식이 아니다.
사용자가 `FinLightAI 카카오톡 채널`을 추가하고, 채널과의 대화방에서 알림을 받는 구조다.

## 사용자에게 보여줄 표현

권장 표현:
- 카카오 채널 추가하기
- 카카오톡 채널로 알림 받기
- 채널 대화로 시장 신호 알림 수신
- 최근 카카오 채널 발송 내역

피해야 할 표현:
- 카카오 연결됨
- 카카오 계정 연결됨
- 개인톡 연결
- 1:1 개인 카카오톡 연결

## 공기계 방식과 채널 방식 차이

| 구분 | 공기계 + 자동화 | 카카오톡 채널 |
|---|---|---|
| 공기계 필요 | 필요 | 불필요 |
| 운영 안정성 | 개인 기기 기반으로 불안정 | 서버/채널 기반으로 상대적으로 안정적 |
| 이동 중 사용 | 제한적 | 가능 |
| 사용 대상 | 본인 카톡 중심 | 채널 친구 전체 |
| 공유 방법 | 대화 상대 추가 | 채널 추가 |

## UI 반영 기준

### 마이페이지

- `카카오 채널 추가하기` CTA를 제공한다.
- 최근 발송 내역은 마이페이지에서 보여준다.
- 상태는 “채널 추가 필요”, “채널 추가됨”, “수신 일시 중지”처럼 채널 기준으로 표현한다.

### 카카오 알림 화면

- 개인 계정 연결 화면처럼 보이지 않게 한다.
- 채널 방식 안내와 메시지 포맷 미리보기를 보여준다.
- 실제 운영 설정은 관리자/서버 측 설정으로 분리한다.

### 상단 버튼

- `카카오 연결됨` 대신 `카카오 채널 추가`를 사용한다.
- 버튼 클릭 시 마이페이지의 카카오 채널 영역으로 유도한다.
