# 테스트 카카오 메시지 포맷

## 목적

카카오 채널 봇으로 발송되는 FinLightAI 알림의 기본 문구 구조를 정의한다.
발표와 개발 테스트에서는 아래 포맷을 기준으로 메시지 미리보기를 구성한다.

## 기본 포맷

```text
[FinLightAI] 🟡 주의 신호

기준: 2026.06.22 09:30
대상: 해외 시장 / 반도체

1. 시장 위험도: 68/100
2. 산업 영향도: 반도체 +78
3. 뉴스 가드: 주의 뉴스 2건

확인 포인트
- 금리 발언 불확실성
- 저신뢰 뉴스 확산 여부
- VIX 변동성 상승

[대시보드에서 자세히 보기]
```

## 신호별 제목 규칙

| 상태 | 제목 | 사용 기준 |
|---|---|---|
| 🔴 위험 | `[FinLightAI] 🔴 위험 신호` | 시장 위험도 75 이상 또는 저신뢰 고영향 뉴스 급증 |
| 🟡 주의 | `[FinLightAI] 🟡 주의 신호` | 시장 위험도 60~74 또는 추가 확인 필요 |
| 🟢 안정 | `[FinLightAI] 🟢 안정 요약` | 큰 위험 신호가 없고 일일 요약 발송 시 |

## 작성 원칙

- 투자 추천처럼 보이는 표현은 사용하지 않는다.
- “매수”, “매도”, “확정 상승”, “수익 보장” 표현을 금지한다.
- 메시지에는 항상 기준 시각, 대상, 위험/영향/뉴스 가드 요약을 포함한다.
- 사용자가 앱으로 돌아와 근거를 확인할 수 있도록 CTA 문구를 포함한다.
