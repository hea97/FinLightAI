# 검색 기능 기준

## 목적

상단 검색창은 디자인 요소가 아니라 실제 탐색 기능으로 동작해야 한다.
사용자는 뉴스, 산업, 주식명을 입력해 관련 화면으로 빠르게 이동할 수 있어야 한다.

## 검색 대상

| 유형 | 예시 | 이동 화면 |
|---|---|---|
| 뉴스 | 미 연준, NVIDIA 공급 병목, 급등 전망 | 뉴스 가드 |
| 산업 | 반도체, 항공, 금융 | 산업 영향도 |
| 주식 | 삼성전자, SK하이닉스, 대한항공 | 포트폴리오 |

## UI 동작

1. 검색어 입력 시 결과 패널을 연다.
2. 결과는 `[유형] 제목`과 보조 설명으로 표시한다.
3. 결과 클릭 시 관련 화면으로 이동한다.
4. 검색 결과가 없으면 “검색 결과가 없습니다” 상태를 보여준다.
5. `Esc` 또는 검색 영역 밖 클릭 시 결과 패널을 닫는다.

## 향후 API 연결

현재는 정적 샘플 데이터 기반이다.
추후 `/api/search?q=` 형태의 통합 검색 API로 교체하면 된다.
