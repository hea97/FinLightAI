## 클릭 상세에 필요한 필드

```ts
type IndustryDetail = {
  name: string;
  score: string;
  badge: string;
  description: string;
  reason: string;
  cause: string;
  assets: string;
  risk: string;
};
```

## 디자인 요청

- 히트맵 카드는 색상만으로 상태를 판단하지 않도록 점수와 상태 라벨을 함께 표시한다.
- 선택된 카드는 border/glow로 강조한다.
- 오른쪽 상세 패널은 산업 정의, 긍정/주의 이유, 관련 종목, 확인 리스크를 구분한다.
