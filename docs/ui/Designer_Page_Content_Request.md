# 디자이너 요청용 페이지별 콘텐츠 정리

## 1. AI 브리핑 / 첫 화면

첫 화면은 `개요`보다 `AI 브리핑` 성격을 강하게 가져간다.

포함 필요 내용:
- 오늘의 핵심 시장 해석
- 기준일 / 마지막 업데이트 시각
- 국내 시장 / 해외 시장 / 관심 산업 탭별로 달라지는 요약 문구
- 시장 위험도 점수와 신호등 상태
- 뉴스 가드 요약
- 산업 영향도 요약
- 사용자가 다음에 확인해야 할 버튼: 뉴스 가드, 산업 영향도, 포트폴리오

디자인 요청:
- 국내 시장 / 해외 시장 / 관심 산업 버튼마다 “왜 눌러야 하는지” 차별화된 설명이 필요
- 포트폴리오 탭은 별도 포트폴리오 페이지와 중복되므로 첫 화면 탭에서는 제외

## 2. 뉴스 가드

포함 필요 내용:
- `[뉴스 채널 이름] [뉴스 제목]` 카드 포맷
- 전체 / 🔴 주의 필요 / 🟡 검토 필요 / 🟢 신뢰 높음 필터
- 영향도 점수
- 신뢰도 상태: 낮음 / 보통 / 높음
- 뉴스 본문 요약
- 의심 사유 또는 신뢰 근거
- 카드 클릭 시 오른쪽 상세 분석 패널 변경

디자인 요청:
- 낮음 / 보통 / 높음의 차이가 색상, 아이콘, 설명 문구에서 확연히 보여야 함
- 발표에서 핵심 기능으로 설명될 예정이므로 신뢰도 판단 기준이 한눈에 보이도록 구성 필요

## 3. 산업 영향도

포함 필요 내용:
- 산업별 히트맵
- 선택 산업명과 영향 점수
- 해당 산업이 무엇을 포함하는지에 대한 짧은 설명
- 긍정/주의/부정 신호가 생긴 이유
- 관련 종목
- 확인해야 할 리스크

디자인 요청:
- 반도체처럼 특정 산업을 선택했을 때 “좋다/나쁘다”뿐 아니라 산업 정의와 근거가 함께 보여야 함

## 4. 포트폴리오

포함 필요 내용:
- 사용자가 직접 등록하는 자산 입력 영역
- 자산명 / 산업 / 비중
- 등록된 관심 자산 목록
- 자산별 오늘 신호
- 관련 뉴스 수
- 실제 매수/매도 기능이 아니라 관심 자산 기반 리스크 확인이라는 안내

디자인 요청:
- “자산 추가” CTA가 명확해야 함
- 사용자가 포트폴리오를 직접 만든다는 느낌이 필요

## 5. 카카오 알림

포함 필요 내용:
- 카카오 채널 연결 상태
- 알림 조건 설정
- 메시지 미리보기
- 최근 발송 내역
- 테스트 알림 보내기
- 정해진 카카오 메시지 포맷

디자인 요청:
- 포트폴리오보다 앞선 핵심 액션은 아니므로 메인 네비게이션에서는 포트폴리오 뒤에 배치
- 메시지 미리보기는 `docs/ui/Kakao_Test_Message.md` 포맷을 기준으로 구성

## 6. 마이페이지

포함 필요 내용:
- 사용자 계정 정보
- 카카오 연결 상태
- 관심 자산 수
- 관심 산업 수
- 카카오 알림 상태
- 포트폴리오 요약
- 개인화 설정

디자인 요청:
- 단순 계정 정보보다 개인화 허브처럼 보여야 함

## 7. 로그인 / 회원가입

포함 필요 내용:
- 첫 방문 또는 상단 `로그인 / 회원가입` CTA 클릭 시에만 노출
- 이메일 로그인
- 카카오 로그인
- 회원가입 흐름 안내
- 투자 추천 서비스가 아니라 신호/근거 제공 서비스라는 안내

디자인 요청:
- 실제 배포 버전에서는 상단 주요 탭으로 항상 노출하지 않음
- 브랜드 옆 또는 상단 우측 CTA로 접근
