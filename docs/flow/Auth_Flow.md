# 로그인 / 회원가입 플로우

## 목표

사용자가 FinLightAI에 자연스럽게 가입하고, 가입 완료 후 마이페이지 또는 자산 포트폴리오 등록으로 이어지도록 한다.

## 사용자 흐름

1. 로그인 / 회원가입 진입
2. 카카오 로그인 또는 이메일 로그인 선택
3. 신규 사용자일 경우 약관 동의
4. 기본 정보 입력
5. 관심 시장과 관심 산업 선택
6. 카카오 채널 알림 동의
7. 가입 완료
8. 마이페이지 이동 또는 자산 포트폴리오 등록 유도

## 화면 구성 제안

### 로그인 화면

- 서비스명과 투자 추천이 아니라 신호/근거 제공 서비스라는 안내
- 카카오로 계속하기 버튼
- 이메일 로그인 폼
- 회원가입 링크
- 비밀번호 찾기 링크

### 회원가입 화면

- 약관 동의
- 이름 / 이메일 / 비밀번호 입력
- 관심 시장 선택
- 관심 산업 선택
- 카카오 채널 알림 동의
- 가입 완료 버튼

### 가입 완료 화면

- 환영 메시지
- “마이페이지로 이동”
- “자산 추가하러 가기”
