# FinLightAI 디자인 전달용 기능 명세서

**문서 목적**: 디자이너가 FinLightAI MVP 화면을 설계할 때 참고할 기능 단위, 메뉴 구조, 화면별 필수 정보, 우선순위를 정리한다.  
**문서 성격**: SRS가 아니라 디자인 지시 및 화면 설계를 위한 기능 명세서이다.  
**작성일**: 2026-06-04  
**기준 방향**: 예쁜 금융 대시보드가 아니라, 사용자가 시장의 소음 속에서 신호와 근거를 찾도록 돕는 AI 금융 상황판

---

## 1. SRS와의 구분

이 문서는 기존 `docs/SRS.md`와 역할이 다르다.

| 문서 | 목적 | 주요 독자 | 다루는 범위 |
|---|---|---|---|
| SRS | 시스템 요구사항 정의 | 개발자, PM | 데이터 수집, 분석, 저장, API, 알림, 비기능 요구사항 |
| 본 문서 | 화면 설계용 기능 명세 | 디자이너, PM, 프론트엔드 개발자 | 메뉴 IA, 화면별 기능 표현, 컴포넌트 우선순위, UX 흐름 |

본 문서는 SRS의 기술 요구사항을 다시 정의하지 않는다. 대신 SRS에 있는 기능들이 사용자 화면에서 어떤 구조와 정보 우선순위로 보여야 하는지 정리한다.

---

## 2. 제품 방향

FinLightAI MVP의 첫인상은 일반 금융 대시보드가 아니라 **AI 금융 상황판**이어야 한다.

핵심 화면 흐름:

```text
시장 선택
→ 오늘의 시장 신호
→ 핵심 지표
→ 산업별 영향도
→ 뉴스 영향도
→ News Guard 경고
→ AI 브리핑
→ 최근 카카오 채널 챗봇 알림
```

이 흐름은 사용자가 다음 질문에 순서대로 답할 수 있게 만든다.

1. 지금 어떤 시장을 보고 있는가?
2. 현재 시장 상태는 어떤가?
3. 어떤 지표가 움직였는가?
4. 어떤 산업이 영향을 받았는가?
5. 어떤 뉴스가 원인인가?
6. 그 뉴스는 믿을 만한가?
7. AI는 어떤 맥락으로 해석하는가?
8. 카카오 채널 챗봇에는 어떤 알림과 응답이 발송되었는가?

## 3. MVP 메뉴 IA

### 3.1 권장 메뉴 구조

```text
Overview
Market Signal
Industry Impact
News Guard
Portfolio
Kakao Channel Bot
Guide
Settings
```

로그인과 회원가입은 사이드 메뉴에 넣지 않고 Auth Flow로 분리한다.

### 3.2 메뉴별 MVP 포함 범위

| 메뉴 | MVP 포함 | 화면 목적 | 비고 |
|---|---|---|---|
| Overview | 필수 | 전체 시장 상황판 | 기존 Dashboard를 대체 |
| Market Signal | 필수 | 시장 지표와 위험도 분석 | 기존 Market 명확화 |
| Industry Impact | 필수 | 산업별 영향도 히트맵 | FinLightAI 핵심 시각 요소 |
| News Guard | 필수 | 뉴스 영향도와 신뢰도 판단 | 핵심 차별 화면 |
| Portfolio | 포함 | 내 관심 자산 요약 | 1차는 요약 중심 |
| Kakao Channel Bot | 필수 | 카카오 채널 챗봇 연결 상태, n8n Webhook 상태, 알림 조건, 응답 내역 확인 | 실사용 흐름을 보여주는 화면 |
| Guide | Lite 포함 | 판단 기준 안내 | 작은 가이드부터 시작 |
| Settings | 필수 | 계정, 관심 시장, 알림 설정 | 개인화 기반 |

### 3.3 제외 또는 변경 대상

| 기존 메뉴 | 결정 | 이유 |
|---|---|---|
| Dashboard | Overview로 변경 | 상황판의 의미를 더 명확히 전달 |
| News | News Guard로 변경 | 일반 뉴스 피드처럼 보이는 문제 방지 |
| Saved | 제외 또는 Watchlist로 변경 | 저장 뉴스보다 관심 종목/산업 관리 의미가 명확함 |
| Login | Auth Flow로 분리 | 메뉴가 아니라 진입 플로우에 해당 |

## 4. Overview 화면 기능 명세

Overview는 MVP의 첫 화면이며 제품의 핵심 인상을 결정한다.

### 4.1 화면 목적

사용자가 진입 직후 현재 시장 상태, 핵심 지표, 산업 영향, 주의 뉴스, AI 해석, 카카오 채널 챗봇 알림 상태를 한눈에 파악하도록 한다.

### 4.2 필수 컴포넌트 순서

| 순서 | 컴포넌트 | 필수 정보 |
|---:|---|---|
| 1 | 시장 선택 필터 | 국내 시장, 미국 시장, 글로벌, 관심 산업, 내 포트폴리오 |
| 2 | 오늘의 시장 요약 | 선택 시장, 전체 신호, 핵심 요약 문장 |
| 3 | 핵심 지표 카드 | KOSPI, NASDAQ, USD/KRW, 금리, VIX, 원유 등 |
| 4 | 산업별 영향도 히트맵 | 산업명, 영향 점수, 상태 라벨, 관련 뉴스 수 |
| 5 | 뉴스 영향도 TOP 5 | 제목, 영향도, 신뢰도, 관련 산업, 상태 |
| 6 | News Guard 경고 | 주의 필요 뉴스 수, 대표 의심 사유 |
| 7 | AI 브리핑 | 오늘의 핵심 해석, 확인 포인트 |
| 8 | 최근 카카오 챗봇 알림 | 발송 시각, 사용자 질문, 챗봇 응답 요약, 상태 |

### 4.3 카피 원칙

수치만 나열하지 않고 맥락을 먼저 보여준다.

| 피해야 할 표현 | 권장 표현 |
|---|---|
| USD/KRW 1,382.50 ▲ 1.2% | 환율 상승으로 수출주에는 긍정, 항공·원자재 부담은 증가 |
| 매수 추천 | 긍정 신호 감지 |
| 매도 추천 | 위험 신호 증가 |
| 지금 사야 함 | 추가 확인 필요 |
| 확실한 상승 | 긍정 가능성 |

## 5. Market Signal 화면 기능 명세

### 5.1 화면 목적

시장별 위험도와 주요 지표 흐름을 보여주고, AI가 왜 현재 신호를 판단했는지 설명한다.

### 5.2 필수 정보

| 항목 | 설명 |
|---|---|
| 시장 선택 | 국내, 미국, 글로벌, 관심 산업 |
| 현재 시장 신호 | RED, YELLOW, GREEN |
| 위험도 점수 | 0~100 범위 |
| 주요 지표 추이 | 지수, 환율, 금리, 변동성, 거래량 |
| AI 시장 해석 | 현재 신호의 이유 |
| 확인해야 할 포인트 | 사용자가 추가로 봐야 할 지표 또는 뉴스 |

### 5.3 디자인 유의사항

- 투자 추천처럼 보이지 않게 한다.
- RED/YELLOW/GREEN은 상태 신호이며 매수/매도 지시가 아니다.
- 숫자 옆에는 상태 라벨과 해석 문장을 함께 둔다.

## 6. Industry Impact 화면 기능 명세

### 6.1 화면 목적

산업별 영향도를 히트맵으로 보여주어 시장 전체 흐름을 빠르게 파악하게 한다.

### 6.2 히트맵 카드 구성

| 요소 | 설명 |
|---|---|
| 산업명 | 반도체, 금융, IT, 자동차, 에너지, 바이오, 항공, 소비재 등 |
| 영향 점수 | -100~+100 |
| 상태 라벨 | 긍정, 약한 긍정, 중립, 주의, 부정 |
| 관련 뉴스 수 | 해당 산업에 연결된 뉴스 개수 |
| 클릭 액션 | 산업 상세 패널 또는 상세 화면으로 이동 |

### 6.3 색상 기준

| 상태 | 점수 범위 예시 | 의미 |
|---|---:|---|
| 긍정 | +40~+100 | 긍정적 영향이 강함 |
| 약한 긍정 | +10~+39 | 일부 긍정 신호 |
| 중립 | -9~+9 | 뚜렷한 방향성 없음 |
| 주의 | -10~-39 | 부정 가능성 존재 |
| 부정 | -40~-100 | 부정적 영향이 강함 |

색상만으로 판단하지 않도록 점수와 라벨을 반드시 함께 제공한다.

### 6.4 상세 패널 필수 정보

- 산업명
- 현재 영향 점수
- 주요 원인 뉴스
- 관련 종목
- AI 해석
- 최근 변화 방향

## 7. News Guard 화면 기능 명세

News Guard는 FinLightAI의 핵심 차별 화면이다. 일반 뉴스 피드처럼 보이면 안 된다.

### 7.1 화면 목적

뉴스의 시장 영향도, 신뢰도, 의심 사유를 함께 보여주어 사용자가 뉴스에 흔들리지 않고 판단 근거를 확인하게 한다.

### 7.2 뉴스 카드 필수 정보

| 항목 | 설명 |
|---|---|
| 뉴스 제목 | 원문 뉴스 제목 |
| 출처 | 언론사 또는 API 출처 |
| 발행 시간 | 최신성 확인 |
| 관련 산업 | 반도체, 금융, 자동차 등 |
| 영향도 점수 | 시장에 미칠 가능성 |
| 신뢰도 점수 | 뉴스 신뢰성 |
| 상태 | 정상, 주의, 과장 가능성, 저신뢰 등 |
| 의심 사유 | 왜 조심해야 하는지 |
| 감성 | 긍정, 부정, 중립, 혼합 |
| 원문 확인 | 사용자가 직접 기사 확인 |

### 7.3 주의 뉴스 카드 예시

```text
[주의 필요 뉴스]

제목: ○○기업 급등 확정 전망
관련 산업: 반도체
영향도: 76
신뢰도: 낮음
상태: 과장 가능성 있음

의심 사유
- 자극적인 표현 사용
- 명확한 근거 부족
- 동일 문장 반복 확산

[원문 확인] [관련 산업 보기]
```

### 7.4 필터

- 전체
- 영향도 높음
- 신뢰도 낮음
- 주의 필요
- 관련 산업
- 발행 시간

## 8. Kakao Channel Bot 화면 기능 명세

### 8.1 화면 목적

대시보드에서 감지한 신호가 카카오 채널 챗봇 알림과 응답으로 이어지는 흐름을 보여준다. 사용자는 어떤 기준으로 어떤 알림이 갔는지, n8n Webhook과 FinLightAI API가 정상 연결되어 있는지 확인할 수 있어야 한다.

### 8.2 MVP 필수 기능

| 기능 | MVP 포함 | 설명 |
|---|---|---|
| 카카오 채널 연결 상태 | 포함 | 카카오 채널 챗봇 연동 상태 표시 |
| n8n Webhook 상태 | 포함 | 카카오 챗봇 요청을 받을 n8n Webhook 연결 상태 표시 |
| 알림 조건 설정 | 포함 | 시장 위험도, 산업 영향도, 뉴스 신뢰도 기준 |
| 테스트 알림 | 포함 | 연결 정상 여부 확인 |
| 최근 발송 내역 | 포함 | 알림 발송 시각과 내용 확인 |
| 상세 로그 | 2차 | 발송 근거 상세 분석 |

### 8.3 알림 조건 예시

```text
알림 조건

[ ] 시장 위험도 70 이상일 때
[ ] 관심 산업 영향도 ±60 이상일 때
[ ] 내 포트폴리오 관련 부정 뉴스 발생 시
[ ] 신뢰도 낮은 뉴스가 확산될 때
[ ] 특정 종목 뉴스가 감지될 때
```

### 8.4 최근 카카오 챗봇 알림 예시

```text
2026.06.04 09:30
반도체 산업 영향도 +78
주의 뉴스 1건 포함
상태: 발송 완료
```

## 9. Portfolio 화면 기능 명세

### 9.1 화면 목적

사용자의 관심 자산 또는 보유 자산을 시장 신호와 뉴스 영향도에 연결한다.

### 9.2 MVP 범위

Portfolio는 유지하되 1차 MVP에서는 요약 중심으로 설계한다.

### 9.3 필수 정보

| 항목 | 설명 |
|---|---|
| 내 관심 자산 | 사용자가 등록한 종목 또는 자산 |
| 내 산업 비중 | 자산이 연결된 산업 비중 |
| 내 자산 관련 뉴스 | 보유 또는 관심 자산과 연결된 뉴스 |
| 포트폴리오 위험 신호 | RED/YELLOW 관련 노출 |

### 9.4 주의사항

- 실제 매수/매도 기능은 제공하지 않는다.
- 개인 투자 추천처럼 보이는 문구를 사용하지 않는다.
- 증권사 계좌 자동 연동은 MVP 범위가 아니다.

## 10. Guide Lite 화면 기능 명세

### 10.1 화면 목적

처음 사용자가 FinLightAI의 판단 기준과 화면 용어를 이해하도록 돕는다.

### 10.2 MVP Guide 구성

1. FinLightAI는 무엇을 하나요?
2. 시장 신호는 어떻게 읽나요?
3. 뉴스 영향도 점수란?
4. 신뢰도 점수란?
5. 가짜 뉴스 의심 기준은?
6. 카카오 채널 챗봇 알림은 언제 발송되나요?

### 10.3 도움말 예시

```text
영향도 점수란?
뉴스가 특정 산업이나 시장에 영향을 줄 가능성을 -100~+100으로 표현한 점수입니다.
```

Guide는 큰 문서형 페이지로 시작하기보다, 각 화면의 작은 도움말과 연결되는 Lite 버전으로 시작한다.

## 12. Auth Flow 기능 명세

### 12.1 화면 목적

금융 서비스에 맞는 신뢰감과 FinLightAI의 서비스 목적을 명확히 전달한다.

### 12.2 로그인 화면 필수 요소

- FinLightAI 브랜드
- 서비스 한 줄 설명
- 이메일
- 비밀번호
- 로그인 버튼
- 회원가입 링크
- 비밀번호 찾기 링크

### 12.3 회원가입 화면 필수 요소

필수 입력:

## 15. 디자이너 전달 요약

FinLightAI MVP는 단순히 차트와 뉴스를 예쁘게 보여주는 서비스가 아니다. 사용자가 금융 정보를 해석할 수 있도록 신호와 근거를 연결해주는 **AI 금융 상황판**으로 보여야 한다.

따라서 첫 화면은 다음 흐름으로 재배치한다.

```text
시장 선택
→ 오늘의 시장 신호
→ 핵심 지표
→ 산업별 히트맵
→ 뉴스 영향도
→ News Guard 경고
→ AI 브리핑
→ 최근 카카오 채널 챗봇 알림
```

가장 중요한 차별점은 News Guard다. 뉴스 화면이 일반 뉴스 피드처럼 보이면 FinLightAI의 정체성이 약해지므로, 영향도 점수, 신뢰도 점수, 의심 사유, 관련 산업, 원문 확인 구조가 반드시 드러나야 한다.

Kakao Channel Bot도 MVP에 포함한다. 이 기능은 대시보드에서 감지한 신호가 카카오 채널 챗봇과 n8n Webhook을 통해 실제 사용자 알림/응답으로 이어지는 흐름을 보여주기 때문에, FinLightAI가 단순 조회형 서비스가 아니라 실사용 가능한 금융 모니터링 도구라는 인상을 준다.
