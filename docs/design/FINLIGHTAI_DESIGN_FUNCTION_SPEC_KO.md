# FinLightAI 최종 디자인 기능 명세서

**작성일**: 2026-06-04  
**최종 리디자인 기준 반영일**: 2026-06-22
**문서 목적**: FinLightAI MVP 화면 설계를 위한 메뉴 IA, 화면별 핵심 정보, UX 흐름, 카피 기준을 정리한다.
**제품 방향**: 다크 테마 기반의 한국어 중심 **AI 금융 상황판**. 시장 신호, 근거, 뉴스 신뢰도, 카카오 알림까지 이어지는 판단 흐름을 보여준다.

## 2. 최종 메뉴 IA

사이드 메뉴는 한국어 중심으로 구성한다.

```text
개요
시장 신호
산업 영향도
뉴스 가드
포트폴리오
카카오 알림
AI 브리핑
설정
```

| 메뉴 | 기존 기능 대응 | 역할 |
|---|---|---|
| 개요 | Dashboard / Home | 전체 시장 상황판 |
| 시장 신호 | Market Signal | 시장 위험도와 핵심 지표 분석 |
| 산업 영향도 | Industry Impact | 산업별 영향도 히트맵 |
| 뉴스 가드 | News Guard | 뉴스 영향도, 신뢰도, 의심 사유 |
| 포트폴리오 | Portfolio | 관심 자산과 관련 뉴스 영향 |
| 카카오 알림 | 기존 Discord Alert 대체 | 카카오 채널 봇 알림 설정/내역 |
| AI 브리핑 | Report + Guide 일부 흡수 | 오늘의 해석, 판단 기준, 요약 |
| 설정 | Settings | 계정, 관심 시장, 알림 설정 |

Guide는 별도 메뉴로 두지 않고 AI 브리핑 하단의 "판단 기준 가이드" 섹션으로 흡수한다.

## 3. 상단 헤더

상단 헤더는 페이지 제목과 짧은 설명을 왼쪽에 두고, 오른쪽에 검색, 언어 전환, 알림, 프로필을 배치한다.

```text
[페이지 제목]
[짧은 설명]                         [검색] [🌐 EN] [알림] [프로필]
```

예시:

```text
개요
오늘의 시장 신호와 주요 뉴스를 한눈에 확인합니다.

검색...    🌐 EN    알림    사용자
```

`🌐 EN` 버튼은 현재 MVP에서 실제 다국어 전환 기능이 없어도 향후 영어 UI 전환 가능성을 보여주는 디자인 요소로 둔다.

## 4. 개요 화면

개요 화면은 FinLightAI의 첫인상이다. 첫 핵심 카드는 반드시 **오늘의 시장 신호 카드**로 배치한다.

### 정보 흐름

```text
시장 선택
-> 오늘의 시장 신호
-> 핵심 지표
-> 산업별 영향도
-> 뉴스 영향도 TOP 5
-> 뉴스 가드 경고
-> AI 브리핑
-> 최근 카카오 알림
```

### 오늘의 시장 신호 카드

```text
오늘의 시장 신호

🟡 주의 신호
위험도 68 / 100

선택 시장: 미국 시장
업데이트: 2026.06.04 09:30

핵심 요약
금리 발언 불확실성과 환율 변동성 증가로 단기 시장 주의가 필요합니다.
반도체 산업은 긍정 신호가 있으나, 저신뢰 뉴스 확산 여부를 함께 확인해야 합니다.

확인 포인트
- 환율 추가 상승 여부
- 반도체 관련 뉴스 신뢰도
- VIX 변동성 지표
```

### 카피 기준

투자 추천처럼 보이는 표현은 피한다.

| 피해야 할 표현 | 변경 표현 |
|---|---|
| 매수 추천 | 긍정 신호 감지 |
| 매도 필요 | 위험 신호 증가 |
| 지금 사야 함 | 추가 확인 필요 |
| 상승 확정 | 긍정 가능성 |
| 폭락 예정 | 위험 신호 확대 |

## 5. 산업 영향도

기존 섹터별 등락률/감성 히트맵 느낌이 아니라 **산업별 영향도 히트맵**으로 설계한다.

### 히트맵 카드 구성

| 요소 | 내용 |
|---|---|
| 산업명 | 반도체, 금융, IT, 자동차 등 |
| 영향 점수 | -100 ~ +100 |
| 상태 라벨 | 긍정 / 약한 긍정 / 중립 / 주의 / 부정 |
| 관련 뉴스 수 | 뉴스 12건 |
| 클릭 시 | 산업 상세 패널 열림 |

예시:

```text
반도체
+78
긍정
뉴스 12건
```

색상만으로 판단하게 만들지 않고 점수와 라벨을 함께 제공한다.

## 6. 뉴스 가드

뉴스 가드는 FinLightAI의 핵심 차별점이다. 일반 뉴스 피드가 아니라 뉴스의 영향도, 신뢰도, 의심 사유를 분리해 보여주는 검증 카드 시스템으로 설계한다.

### 뉴스 카드 구조

```text
주의 필요 뉴스

제목: ○○기업 급등 확정 전망
출처: 출처불명
발행 시간: 09:30
관련 산업: 반도체

영향도: 76
신뢰도: 낮음
상태: 과장 가능성 있음
감성: 혼합

의심 사유
- 자극적인 표현 사용
- 명확한 근거 부족
- 동일 문장 반복 확산

[원문 확인] [관련 산업 보기]
```

영향도와 신뢰도는 반드시 분리해서 보여준다.

| 항목 | 의미 |
|---|---|
| 영향도 | 시장이나 산업에 영향을 줄 가능성 |
| 신뢰도 | 뉴스 자체를 조심해서 봐야 하는 정도 |

## 7. 카카오 알림

기존 Discord 화면은 카카오 채널 봇 알림 관리 화면으로 변경한다.

### 화면 구성

| 섹션 | 내용 |
|---|---|
| 카카오 채널 연결 상태 | 연결됨, 채널명, 봇 상태, 마지막 테스트 |
| 알림 조건 설정 | 어떤 상황에서 알림을 보낼지 |
| 메시지 미리보기 | 카카오톡 말풍선 형태 |
| 최근 발송 내역 | 발송 시각, 알림 유형, 트리거 원인, 발송 상태 |
| 실패/차단 상태 | 발송 실패나 수신 불가 상태 |

### 알림 조건

- 시장 위험도 70 이상
- 관심 산업 영향도 ±60 이상
- 신뢰도 낮은 뉴스 감지
- 내 포트폴리오 관련 부정 뉴스 발생
- RED 신호 발생

### 메시지 미리보기 예시

```text
FinLightAI

🟡 주의 신호 감지

미국 시장 위험도 68
반도체 산업 영향도 +78
주의 뉴스 2건 감지

확인 포인트
- 금리 발언 불확실성
- 저신뢰 뉴스 확산 여부
- VIX 변동성 상승

[대시보드에서 자세히 보기]
```

Discord 임베드 스타일은 제외하고 카카오톡 말풍선 UI처럼 보여준다.

## 8. AI 브리핑

Report와 Guide는 AI 브리핑으로 흡수한다.

### AI 브리핑 구성

1. 오늘의 핵심 해석
2. 시장 신호 판단 근거
3. 뉴스 가드 요약
4. 산업별 주요 변화
5. 카카오 알림 발송 요약
6. 판단 기준 가이드

### 판단 기준 가이드

AI 브리핑 하단에 다음 질문형 가이드를 둔다.

- 시장 신호는 어떻게 읽나요?
- 영향도 점수란?
- 신뢰도 점수란?
- 가짜 뉴스 의심 기준은?
- 카카오 알림은 언제 발송되나요?

## 10. 최종 방향

기존 다크 대시보드의 분위기는 유지하되, 최신 기능 명세서를 기준으로 화면 구조를 한국어 중심의 AI 금융 상황판으로 재구성한다.

최종 IA:

```text
개요
시장 신호
산업 영향도
뉴스 가드
포트폴리오
카카오 알림
AI 브리핑
설정
```

첫 화면 핵심은 오늘의 시장 신호 카드다. 첫 화면 흐름은 시장 선택에서 시작해 오늘의 시장 신호, 핵심 지표, 산업 영향도, 뉴스 영향도, 뉴스 가드 경고, AI 브리핑, 최근 카카오 알림으로 이어진다.
