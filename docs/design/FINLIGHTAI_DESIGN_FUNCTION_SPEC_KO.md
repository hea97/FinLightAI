**작성일**: 2026-06-04
**최종 업데이트**: 2026-06-23
**대상**: 디자이너, 프론트엔드 개발자, 발표용 MVP 제작자
**문서 목적**: FinLightAI MVP의 화면 IA, 페이지별 기능, 콘텐츠 우선순위, 상호작용, 카카오 챗봇/n8n 흐름, 카피 기준을 정리한다.

## 1. 제품 방향

FinLightAI는 투자 추천 서비스가 아니라 **AI 금융 상황판**이다.

뉴스, 시장 지표, 산업 영향도, 포트폴리오 관심 자산을 함께 분석해 사용자가 현재 시장 상태를 빠르게 이해하도록 돕는다. MVP의 핵심은 실제 운영 서비스 완성보다 발표와 시연에서 제품 가치를 명확히 보여주는 것이다.

### 핵심 가치

- RED / YELLOW / GREEN 시장 신호로 현재 시장 상태를 보여준다.
- 뉴스의 **영향도**와 **신뢰도**를 분리해 보여준다.
- 산업별 영향도를 히트맵과 상세 패널로 설명한다.
- 포트폴리오 관심 자산과 시장/뉴스 리스크를 연결한다.
- 카카오 채널 챗봇과 n8n Webhook을 통해 시장 신호 확인 흐름을 보여준다.

### 표현 원칙

투자 지시처럼 보이는 문구는 사용하지 않는다.

| 피해야 할 표현 | 사용 표현 |
|---|---|
| 매수 추천 | 긍정 신호 감지 |
| 매도 필요 | 위험 신호 증가 |
| 지금 사야 함 | 추가 확인 필요 |
| 상승 확정 | 긍정 가능성 |
| 폭락 예정 | 위험 신호 확대 |
| 수익 보장 | 참고용 시장 상태 |

## 4. 공통 화면 구조

### 상단 헤더

상단 헤더는 제품 네비게이션, 검색, 언어 전환, 알림, 프로필을 포함한다.

```text
[FinLightAI] [AI 브리핑] [뉴스 가드] [산업 영향도] [포트폴리오] [카카오 알림]
                                                   [검색] [알림] [프로필]
```

### 공통 인터랙션

| 영역 | 동작 |
|---|---|
| 화면 네비게이션 | 상단 탭 클릭 시 화면 전환 |
| 국내/해외/관심 산업 탭 | 헤드라인, 요약, KPI 카드 변경 |
| 뉴스 가드 필터 | 전체 / 주의 필요 / 검토 필요 / 신뢰 높음 카드 필터링 |
| 뉴스 카드 | 클릭 시 상세 분석 패널 변경 |
| 산업 히트맵 | 클릭 시 선택 산업 상세 설명 변경 |
| 포트폴리오 | 자산 등록 폼 열기/닫기, 자산 추가 |
| 검색 | 뉴스/산업/주식 검색 후 관련 화면 이동 |
| 언어 | MVP에서는 한국어 고정. KO/EN 전환은 발표 이후 확장 범위로 이동 |

### 상태 관리 기준

향후 React 전환 시 아래 상태를 기준으로 컴포넌트를 분리한다.

```js
const appState = {
  screen: 'overview',
  lang: 'ko',
  market: 'global',
  newsFilter: 'all',
  selectedNews: 'rumor',
  selectedIndustry: 'semiconductor',
  portfolioFormOpen: false
};
```

## 5. AI 브리핑 / 첫 화면

첫 화면은 단순 `개요`가 아니라 **AI 브리핑 성격의 시장 상황판**이다. 사용자가 들어오자마자 오늘 무엇을 확인해야 하는지 판단하게 만든다.

### 정보 우선순위

1. 오늘의 시장 신호
2. AI 브리핑 요약
3. 주요 지표 카드
4. 산업별 영향도 히트맵
5. 뉴스 영향도 TOP 5
6. 뉴스 가드 경고
7. 최근 카카오 채널 발송 내역

### 첫 화면 레이아웃 기준

Desktop 12-column grid 기준:

- 1행: 오늘의 시장 신호 8 / AI 브리핑 요약 4
- 2행: 주요 지표 카드 5 / 산업 히트맵 7
- 3행: 뉴스 TOP 5 5 / 뉴스 가드 경고 3 / 최근 카카오 알림 4

Tablet은 6-column, Mobile은 1-column 기준으로 재배치한다.

### 시장 탭

| 탭 | 포함 내용 | 역할 |
|---|---|---|
| 국내 시장 | KOSPI, KOSDAQ, USD/KRW, 국내 금리, 국내 뉴스 | 한국 시장에 직접 영향을 주는 지표 확인 |
| 해외 시장 | NASDAQ, S&P 500, DOW, VIX, WTI, 미국 금리 | 글로벌 위험 신호와 미국 기술주 흐름 확인 |
| 관심 산업 | 관심 산업, 관련 종목, 관련 뉴스, 포트폴리오 위험 신호 | 사용자의 관심 산업 중심 개인화 |

포트폴리오 탭은 별도 포트폴리오 페이지와 중복되므로 첫 화면 탭에서는 제외한다.

### 오늘의 시장 신호 카드 예시

```text
오늘의 시장 신호

🟡 주의 신호
위험도 68 / 100

기준: 2026.06.23 09:30
대상: 해외 시장 / 반도체

핵심 요약
금리 발언 불확실성과 VIX 변동성 상승으로 단기 시장 주의가 필요합니다.
반도체 산업은 긍정 신호가 있으나, 저신뢰 뉴스 확산 여부를 함께 확인해야 합니다.

확인 포인트
- 환율 추가 상승 여부
- 반도체 관련 뉴스 신뢰도
- VIX 변동성 지표
```

## 6. 뉴스 가드

뉴스 가드는 FinLightAI의 핵심 차별점이다. 단순 뉴스 목록이 아니라 뉴스의 영향도, 신뢰도, 주의 사유를 분리해서 보여주는 검증 시스템이다.

### 포함 요소

- `[뉴스 채널 이름] [뉴스 제목]` 카드 포맷
- 전체 / 🔴 주의 필요 / 🟡 검토 필요 / 🟢 신뢰 높음 필터
- 영향도 점수
- 신뢰도 상태: 낮음 / 보통 / 높음
- 뉴스 본문 요약
- 의심 사유 또는 신뢰 근거
- 카드 클릭 시 오른쪽 상세 분석 패널 변경

### 뉴스 카드 예시

```text
주의 필요 뉴스

출처: 출처불명
제목: ○○기업 급등 확정 전망
발행 시간: 09:30
관련 산업: 반도체

영향도: 76
신뢰도: 낮음
상태: 과장 가능성 있음
감성: 혼합

의심 사유
- 자극적인 표현 사용
- 명확한 근거 부족
- 동일 문장 반복 확산

[원문 확인] [관련 산업 보기]
```

### 영향도와 신뢰도 정의

| 항목 | 의미 |
|---|---|
| 영향도 | 시장이나 산업에 영향을 줄 가능성 |
| 신뢰도 | 뉴스 자체를 조심해서 봐야 하는 정도 |

신뢰도 낮음 / 보통 / 높음의 차이는 색상, 아이콘, 설명 문구에서 확연히 보여야 한다.

## 7. 산업 영향도

산업 영향도는 기존 섹터 등락률이 아니라 **뉴스와 시장 반응이 어떤 산업에 영향을 주는지** 보여주는 화면이다.

### 포함 요소

- 산업별 히트맵
- 선택 산업명과 영향 점수
- 해당 산업이 무엇을 포함하는지에 대한 짧은 설명
- 긍정/주의/부정 신호가 생긴 이유
- 관련 종목
- 확인해야 할 리스크
- 산업 카드 클릭 시 오른쪽 상세 패널 변경

### 히트맵 카드 구성

| 요소 | 내용 |
|---|---|
| 산업명 | 반도체, 금융, 자동차, 에너지, 바이오, 항공, IT 등 |
| 영향 점수 | -100 ~ +100 |
| 상태 라벨 | 긍정 / 약한 긍정 / 중립 / 주의 / 부정 |
| 관련 뉴스 수 | 뉴스 12건 |
| 클릭 시 | 산업 상세 패널 열림 |

예시:

```text
반도체
+78
긍정
뉴스 12건
```

색상만으로 판단하게 만들지 않고 점수와 라벨을 함께 제공한다.

## 8. 포트폴리오

포트폴리오는 실제 매수/매도 기능이 아니라 **관심 자산 기반 리스크 확인** 기능이다.

### 포함 요소

- 사용자가 직접 등록하는 자산 입력 영역
- 자산명 / 산업 / 비중
- 등록된 관심 자산 목록
- 자산별 오늘 신호
- 관련 뉴스 수
- 포트폴리오 리스크 신호
- 실제 매수/매도 기능이 아니라는 안내

### CTA 기준

빈 상태와 주요 CTA에서 “자산 추가하기”를 명확하게 노출한다.

```text
아직 등록된 관심 자산이 없습니다.
관심 자산을 추가하면 시장 신호와 관련 뉴스를 함께 확인할 수 있습니다.

[자산 추가하기]
```

사용자가 포트폴리오를 직접 만든다는 느낌이 필요하다.

## 9. 카카오 알림 / 카카오 채널 챗봇

기존 Discord Bot 방향은 카카오 채널 챗봇 + n8n Webhook 구조로 전환한다.

### 화면 구성

| 섹션 | 내용 |
|---|---|
| 카카오 채널 연결 상태 | 연결됨, 채널명, 봇 상태, 마지막 테스트 |
| n8n Webhook 상태 | Webhook URL, 마지막 응답, 실패 여부 |
| 알림 조건 설정 | 어떤 상황에서 알림을 보낼지 |
| 메시지 미리보기 | 카카오톡 말풍선 형태 |
| 최근 발송 내역 | 발송 시각, 알림 유형, 트리거 원인, 발송 상태 |
| 테스트 알림 | 테스트 카카오 메시지 보내기 |

### 알림 조건

- 시장 위험도 70 이상
- 관심 산업 영향도 ±60 이상
- 신뢰도 낮은 뉴스 감지
- 내 포트폴리오 관련 부정 뉴스 발생
- RED 신호 발생
- 일일 AI 브리핑 요약

### 카카오 메시지 기본 포맷

```text
[FinLightAI] 🟡 주의 신호

기준: 2026.06.23 09:30
대상: 해외 시장 / 반도체

1. 시장 위험도: 68/100
2. 산업 영향도: 반도체 +78
3. 뉴스 가드: 주의 뉴스 2건

확인 포인트
- 금리 발언 불확실성
- 저신뢰 뉴스 확산 여부
- VIX 변동성 상승

[대시보드에서 자세히 보기]
```

### 챗봇 + n8n 흐름

```text
사용자 카카오 채널 메시지
-> 카카오 채널 챗봇
-> n8n Webhook
-> FinLightAI API
-> n8n 응답 가공
-> 카카오 채널 챗봇 응답
```

발표용 질문 예시:

- 오늘 시장 신호 알려줘
- 주의 뉴스 있어?
- 반도체 영향도 보여줘
- 내 포트폴리오 리스크 알려줘
- RED 신호 이유가 뭐야?

Discord 임베드 스타일은 제외하고 카카오톡 말풍선 UI처럼 보여준다.

## 10. 마이페이지

마이페이지는 단순 계정 정보 화면이 아니라 개인화 허브처럼 보여야 한다.

### 포함 요소

- 사용자 계정 정보
- 카카오 연결 상태
- 관심 자산 수
- 관심 산업 수
- 카카오 알림 상태
- 포트폴리오 요약
- 개인화 설정

마이페이지에서 사용자가 “내 관심 자산과 알림이 어떻게 연결되어 있는지” 이해할 수 있어야 한다.

## 11. 로그인 / 회원가입

로그인/회원가입은 첫 방문 또는 상단 CTA 클릭 시에만 노출한다.

### 포함 요소

- 이메일 로그인
- 카카오 로그인
- 회원가입 흐름 안내
- 약관 동의
- 기본 정보 입력
- 가입 완료 후 마이페이지 또는 자산 등록 유도
- 투자 추천 서비스가 아니라 신호/근거 제공 서비스라는 안내

실제 배포 버전에서는 상단 주요 탭으로 항상 노출하지 않는다.

## 13. 접근성 및 UX 보강

향후 개선 기준:

- 키보드 포커스 이동
- 선택 상태 `aria` 속성
- 버튼 hover / active / selected 상태 통일
- 검색 결과 empty state
- 뉴스 필터 empty state
- 모바일에서 카드 겹침과 가로 스크롤 방지

마이크로 인터랙션:

- 화면 전환: fade + slide-up
- 탭 hover: 1px 위로 이동
- 카드 hover: border 강조
- 선택 카드: outline/glow 강조
- 포트폴리오 등록 폼: 짧은 등장 애니메이션

## 15. 발표 시연 순서

1. FinLightAI가 무엇인지 설명한다.
2. 투자 추천이 아니라 시장 상태 신호 도구라고 설명한다.
3. AI 브리핑에서 전체 시장 상태를 보여준다.
4. 뉴스 가드에서 뉴스 신뢰도와 주의 사유를 보여준다.
5. 산업 영향도에서 산업별 영향도와 근거를 보여준다.
6. 포트폴리오에서 관심 자산과 시장 신호의 연결을 보여준다.
7. 카카오 알림에서 카카오 채널 챗봇 + n8n 흐름을 설명한다.
8. 향후 실제 운영 계획을 설명한다.
