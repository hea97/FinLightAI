# FinLightAI 현재 방향성과 목표 계획서

작성일: 2026-06-21
목표 완료일: 2026-06-24
발표일: 2026-06-26

## 1. 현재 목표

FinLightAI는 AI, 반도체, 정책, 금융 뉴스와 시장 데이터를 결합해 사용자가 현재 시장 상태를 빠르게 이해하도록 돕는 금융 신호 대시보드다.

6월 26일 발표 목표는 완전한 운영 서비스가 아니라, FinLightAI의 핵심 가치와 사용 흐름을 명확히 보여주는 발표 가능한 MVP를 완성하는 것이다.

이번 MVP에서 보여줄 핵심은 다음과 같다.

- 뉴스와 시장 데이터를 종합해 RED/YELLOW/GREEN 시장 신호를 보여준다.
- 뉴스의 신뢰도와 영향도를 함께 보여줘 사용자가 뉴스를 그대로 믿지 않도록 돕는다.
- 산업별 영향도를 한눈에 보여준다.
- 포트폴리오와 연결해 사용자가 관심 자산의 리스크를 이해할 수 있게 한다.
- 기존 Discord Bot 방향을 카카오 채널 챗봇 + n8n Webhook 구조로 전환한다.

## 2. 제품 방향

FinLightAI는 투자 추천 서비스가 아니다.

서비스 표현 원칙:

- 매수, 매도, 수익 보장 표현을 사용하지 않는다.
- 모든 결과는 참고용 시장 상태, 뉴스 리스크, 포트폴리오 현황 정보로 제공한다.
- RED/YELLOW/GREEN은 투자 지시가 아니라 시장 상태 신호다.
- News Guard는 단순 뉴스 목록이 아니라 신뢰도, 영향도, 주의 사유를 함께 보여주는 핵심 차별점이다.

## 3. 6월 24일까지 완성할 범위

6월 24일까지는 발표 가능한 MVP를 목표로 한다.

반드시 완료할 것:

- 현재 대시보드 디자인 전면 교체
- 깨진 한글과 깨진 UI 구조 복구
- 주요 메뉴 구조 정리
- Overview 화면 완성
- Market Signal 화면 완성
- Industry Impact 화면 완성
- News Guard 화면 완성
- Portfolio 요약 화면 완성
- Kakao Channel Bot 화면 완성
- 발표용 mock 데이터 정리
- 로컬 실행 및 기본 테스트 통과
- 배포 가능 상태 정리

완성 기준:

- 첫 화면 접속 시 깨진 한글이 없어야 한다.
- 주요 메뉴를 클릭했을 때 화면 전환이 정상 작동해야 한다.
- RED/YELLOW/GREEN 신호의 의미가 화면에서 이해되어야 한다.
- News Guard의 신뢰도/영향도/주의 사유가 명확히 보여야 한다.
- Kakao Channel Bot 화면에서 n8n 기반 연동 흐름이 설명 가능해야 한다.
- 발표자가 3~5분 안에 서비스 흐름을 시연할 수 있어야 한다.

## 4. 발표 이후로 미룰 범위

아래 항목은 발표 전까지 완성 목표로 두지 않는다.

- 실제 OAuth 로그인
- 실제 카카오 채널 정식 운영 심사 완료
- 실제 사용자별 포트폴리오 저장
- PostgreSQL 운영 DB 완전 연결
- 실제 뉴스/주가 API 완전 자동화
- ML 모델 고도화
- 결제, 권한, 관리자 기능
- 증권 계좌 자동 연동

발표 전에는 mock 데이터와 데모 흐름을 활용하되, 실제 서비스로 확장 가능한 구조를 명확히 설명한다.

## 5. 화면 구성 목표

### Overview

목표:

- 사용자가 들어오자마자 현재 시장 상태를 이해한다.

포함 요소:

- 오늘의 시장 신호
- 핵심 지표
- 산업 영향 요약
- 주의 뉴스
- AI 브리핑
- 최근 카카오 챗봇 알림 상태

### Market Signal

목표:

- RED/YELLOW/GREEN 신호가 왜 나왔는지 설명한다.

포함 요소:

- 현재 신호
- 위험도 점수
- 주요 판단 근거
- 시장 지표 변화
- 확인해야 할 포인트

### Industry Impact

목표:

- 뉴스와 시장 반응이 어떤 산업에 영향을 주는지 보여준다.

포함 요소:

- 산업별 영향도
- 영향 점수
- 긍정/주의/부정 상태
- 관련 뉴스 수
- 상세 설명 패널

### News Guard

목표:

- 뉴스 신뢰도와 영향도를 함께 보여준다.

포함 요소:

- 뉴스 제목
- 출처
- 발행 시각
- 관련 산업
- 영향도 점수
- 신뢰도 점수
- 주의 사유
- 원문 확인

### Portfolio

목표:

- 사용자의 관심 자산 또는 예시 포트폴리오가 시장 신호와 어떻게 연결되는지 보여준다.

포함 요소:

- 관심 자산 목록
- 섹터 비중
- 자산별 관련 뉴스
- 포트폴리오 리스크 신호

### Kakao Channel Bot

목표:

- 카카오 채널 챗봇과 n8n을 통해 시장 신호를 빠르게 확인하는 흐름을 보여준다.

포함 요소:

- 카카오 채널 연결 상태
- n8n Webhook 연결 상태
- 사용자 질문 예시
- 최근 챗봇 응답 내역
- 자동 알림 조건
- 테스트 메시지 흐름

## 6. 카카오 채널 챗봇 및 n8n 방향

기존 Discord Bot 방향은 카카오 채널 챗봇 중심으로 변경한다.

연동 구조:

```text
사용자 카카오 채널 메시지
-> 카카오 채널 챗봇
-> n8n Webhook
-> FinLightAI API
-> n8n 응답 가공
-> 카카오 채널 챗봇 응답
```

발표용 질문 예시:

- 오늘 시장 신호 알려줘
- 주의 뉴스 있어?
- 반도체 영향도 보여줘
- 내 포트폴리오 리스크 알려줘
- RED 신호 이유가 뭐야?

발표 전 목표:

- 실제 카카오 심사 완료보다 흐름 설명과 화면 시연을 우선한다.
- n8n Webhook 구조를 명확히 보여준다.
- 실제 운영에서는 카카오 채널 심사, 사용자 인증, 로그 저장을 추가한다고 설명한다.

1. FinLightAI가 무엇인지 설명한다.
2. 투자 추천이 아니라 시장 상태 신호 도구라고 설명한다.
3. Overview에서 전체 시장 상태를 보여준다.
4. Market Signal에서 신호 판단 근거를 보여준다.
5. Industry Impact에서 산업별 영향도를 보여준다.
6. News Guard에서 뉴스 신뢰도와 주의 사유를 보여준다.
7. Portfolio에서 관심 자산과 시장 신호의 연결을 보여준다.
8. Kakao Channel Bot에서 카카오 챗봇 + n8n 흐름을 설명한다.

## 10. 최종 판단

6월 24일까지 발표 가능한 MVP 완성은 가능하다. 단, 기능을 넓히기보다 화면 완성도, 설명 가능성, 시연 안정성에 집중해야 한다.

가장 중요한 성공 기준은 다음 세 가지다.

1. 사용자가 FinLightAI의 목적을 10초 안에 이해한다.
2. News Guard와 RED/YELLOW/GREEN 신호의 차별점이 명확히 보인다.
3. 카카오 채널 챗봇 + n8n 전환이 실제 서비스 확장 방향으로 설득력 있게 보인다.
