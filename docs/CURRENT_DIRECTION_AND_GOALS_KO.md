# FinLightAI 현재 방향성과 목표 계획서

작성일: 2026-06-21
최종 업데이트: 2026-06-25
기준 브랜치: `main`

## 1. 현재 목표

FinLightAI는 AI, 반도체, 정책, 금융 뉴스와 시장 데이터를 결합해 사용자가 현재 시장 상태를 빠르게 이해하도록 돕는 AI 금융 상황판이다.

현재 목표는 완전한 운영 서비스가 아니라, 핵심 가치와 사용 흐름을 명확히 보여주는 발표/검증 가능한 MVP를 완성하는 것이다.

이번 MVP에서 보여줄 핵심은 다음과 같다.

- 뉴스와 시장 데이터를 종합해 RED/YELLOW/GREEN 시장 신호를 보여준다.
- 뉴스의 신뢰도와 영향도를 분리해 사용자가 뉴스를 그대로 믿지 않도록 돕는다.
- 산업별 영향도를 한눈에 보여주고, 산업 선택 시 상세 근거를 제공한다.
- 관심 자산 포트폴리오와 연결해 사용자가 자산별 리스크를 이해할 수 있게 한다.
- 기존 Discord Bot 방향은 중단하고, 카카오 채널 챗봇 + n8n Webhook 구조로 전환한다.
- React 기반 프론트엔드에서 화면별 mock data, type, service 계층을 분리해 실제 API 연결 준비 상태로 만든다.

## 2. 제품 방향

FinLightAI는 투자 추천 서비스가 아니다.

서비스 표현 원칙:

- 매수, 매도, 수익 보장, 상승 확정 표현을 사용하지 않는다.
- 모든 결과는 참고용 시장 상태, 뉴스 리스크, 포트폴리오 현황 정보로 제공한다.
- RED/YELLOW/GREEN은 투자 지시가 아니라 시장 상태 신호다.
- News Guard는 단순 뉴스 목록이 아니라 신뢰도, 영향도, 주의 사유를 함께 보여주는 핵심 차별점이다.
- 카카오 알림은 투자 행동 유도가 아니라 상태 요약과 근거 확인 CTA로 제한한다.

## 3. 최신 구현 기준

현재 프론트엔드는 `frontend/` 아래 Vite + React + TypeScript 구조로 정리되어 있다.

주요 화면:

- AI 브리핑
- 뉴스 가드
- 산업 영향도
- 포트폴리오
- 카카오 알림
- 마이페이지
- 설정
- 로그인 / 회원가입 흐름

주요 코드 구조:

- 화면 컨테이너: `frontend/src/App.tsx`
- 공통 시장/브리핑 mock: `frontend/src/data/mockData.ts`
- 화면별 mock data: `frontend/src/data/*.mock.ts`
- 화면별 타입: `frontend/src/types/*.ts`
- 화면별 API service: `frontend/src/services/*Api.ts`

현재 service 계층은 `USE_MOCK = true` 기준으로 mock data를 반환하며, 이후 FastAPI endpoint와 연결할 수 있도록 분리되어 있다.

## 4. MVP 완성 범위

반드시 포함할 것:

- AI 브리핑 첫 화면
- 국내 시장 / 해외 시장 / 관심 산업 탭
- 오늘의 시장 신호와 위험도 점수
- 뉴스 영향도 TOP 5
- 뉴스 가드의 신뢰 뉴스 / 주의 뉴스 / 차단 뉴스 필터
- 산업 영향도 히트맵과 상세 패널
- 관심 자산 추가/수정/삭제 UI
- 포트폴리오 평가금액, 손익, 관련 뉴스, 산업 연결
- 카카오 알림 조건, 메시지 미리보기, n8n 흐름 설명
- 마이페이지 개인화 허브
- 설정 화면의 데이터/API/알림/표시 설정
- 로그인/회원가입 및 온보딩 흐름

완성 기준:

- 첫 화면 접속 시 깨진 한글이 없어야 한다.
- 주요 화면 전환이 정상 작동해야 한다.
- RED/YELLOW/GREEN 신호의 의미가 화면에서 이해되어야 한다.
- News Guard의 신뢰도/영향도/주의 사유가 명확히 보여야 한다.
- Portfolio가 실제 매매 기능이 아니라 관심 자산 기반 리스크 확인 기능임을 이해할 수 있어야 한다.
- Kakao Alert 화면에서 카카오 채널 챗봇 + n8n 기반 연동 흐름을 설명할 수 있어야 한다.
- 발표자가 3~5분 안에 서비스 흐름을 시연할 수 있어야 한다.

## 5. 발표 이후로 미룰 범위

아래 항목은 발표 전까지 완성 목표로 두지 않는다.

- 실제 OAuth 운영 연결
- 실제 카카오 채널 정식 운영 심사 완료
- 실제 사용자별 포트폴리오 서버 저장
- PostgreSQL 운영 DB 완전 연결
- 실제 뉴스/주가 API 완전 자동화
- 실제 n8n 운영 workflow 배포
- ML 모델 고도화
- 결제, 권한, 관리자 기능
- 증권 계좌 자동 연동

발표 전에는 mock data와 데모 흐름을 활용하되, 실제 서비스로 확장 가능한 구조를 명확히 설명한다.

## 6. 화면 구성 목표

### AI 브리핑

목표:

- 사용자가 들어오자마자 현재 시장 상태를 이해한다.

포함 요소:

- 오늘의 시장 신호
- 시장 위험도 점수
- AI 브리핑 요약
- 주요 지표
- 뉴스 영향도 TOP 5
- 산업 영향도 요약
- 뉴스 가드 경고
- 최근 카카오 알림 상태

### 뉴스 가드

목표:

- 뉴스 신뢰도와 영향도를 분리해서 보여준다.

포함 요소:

- 수집 뉴스 수
- 신뢰 뉴스 / 주의 뉴스 / 차단 뉴스 카운트
- 평균 신뢰도
- provider 상태
- 뉴스 카드 목록
- 신뢰도 점수, 영향도 점수, 감성 점수
- 차단/주의 사유

### 산업 영향도

목표:

- 뉴스와 시장 반응이 어떤 산업에 영향을 주는지 보여준다.

포함 요소:

- 산업별 영향도 점수
- 긍정/주의/부정 상태
- 관련 뉴스 수
- 관련 종목
- 선택 산업 상세 설명 패널

### 포트폴리오

목표:

- 사용자의 관심 자산이 시장 신호와 어떻게 연결되는지 보여준다.

포함 요소:

- 관심 자산 목록
- 자산 추가/수정/삭제
- 평가금액과 평가손익
- 산업 연결
- 관련 뉴스 수
- 자산별 주의 뉴스 수
- 실제 매매 기능이 아님을 안내

### 카카오 알림

목표:

- 카카오 채널 챗봇과 n8n을 통해 시장 신호를 빠르게 확인하는 흐름을 보여준다.

포함 요소:

- 카카오 채널 연결 상태
- n8n Webhook 연결 상태
- 사용자 질문 예시
- 최근 챗봇 응답 내역
- 자동 알림 조건
- 테스트 메시지 미리보기

### 마이페이지

목표:

- 계정, 관심 산업, 관심 자산, 알림 상태를 개인화 허브로 제공한다.

포함 요소:

- 사용자 프로필
- 관심 산업
- 관심 자산 요약
- 카카오 연결 상태
- 알림 설정 요약
- 바로가기

### 설정

목표:

- 데이터 수집, 뉴스 가드, 알림, API 연결, 표시 설정을 관리한다.

포함 요소:

- 데이터 수집 설정
- 뉴스 가드 민감도
- 카카오 알림 설정
- API 연결 상태
- 한국어 고정 MVP 표시 설정

## 7. 카카오 채널 챗봇 및 n8n 방향

기존 Discord Bot 방향은 카카오 채널 챗봇 중심으로 변경한다.

연동 구조:

```text
사용자 카카오 채널 메시지
-> 카카오 채널 챗봇
-> n8n Webhook
-> FinLightAI API
-> n8n 응답 가공
-> 카카오 채널 챗봇 응답
```

발표용 질문 예시:

- 오늘 시장 신호 알려줘
- 주의 뉴스 있어?
- 반도체 영향도 보여줘
- 내 포트폴리오 리스크 알려줘
- RED 신호 이유가 뭐야?

발표 전 목표:

- 실제 카카오 심사 완료보다 흐름 설명과 화면 시연을 우선한다.
- n8n Webhook 구조를 명확히 보여준다.
- 실제 운영에서는 카카오 채널 심사, 사용자 인증, 로그 저장을 추가한다고 설명한다.

## 9. 발표 시연 순서

1. FinLightAI가 무엇인지 설명한다.
2. 투자 추천이 아니라 시장 상태 신호 도구라고 설명한다.
3. AI 브리핑에서 전체 시장 상태를 보여준다.
4. 뉴스 가드에서 뉴스 신뢰도와 주의 사유를 보여준다.
5. 산업 영향도에서 산업별 영향도를 보여준다.
6. 포트폴리오에서 관심 자산과 시장 신호의 연결을 보여준다.
7. 카카오 알림에서 카카오 채널 챗봇 + n8n 흐름을 설명한다.
8. 마이페이지와 설정에서 개인화/운영 확장 가능성을 보여준다.
9. 향후 실제 운영 계획을 설명한다.

## 10. 최종 판단

현재 MVP는 React 기반 화면 시연과 mock data 기반 흐름 검증에 집중한다. 기능을 더 넓히기보다 화면 완성도, 설명 가능성, 시연 안정성에 집중해야 한다.

가장 중요한 성공 기준은 다음 세 가지다.

1. 사용자가 FinLightAI의 목적을 10초 안에 이해한다.
2. News Guard와 RED/YELLOW/GREEN 신호의 차별점이 명확히 보인다.
3. 카카오 채널 챗봇 + n8n 전환이 실제 서비스 확장 방향으로 설득력 있게 보인다.
